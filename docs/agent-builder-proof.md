# Google Cloud Agent Builder Proof

## Agent Name

YOUSUN Amicus Loan Review Agent

## Purpose

YOUSUN Amicus is a financial twin agent for fair lending and rescue before default.

It helps bank officers review SME loan applications, generate Gemini-powered reports, and create early support plans before a borrower reaches default.

## Agent Builder Integration Method

The project exposes OpenAPI-defined tool endpoints that are ready for Google Cloud Agent Builder orchestration.

These tools allow an agent to move beyond chat and complete real workflow actions:

- Review a loan application
- Generate a responsible lending analysis
- Create Gemini-powered reports
- Prepare rescue-before-default actions
